# TraceIMEI-BJ

Plateforme de traçabilité des téléphones au Bénin. Ce dépôt contient l'application web du projet.

## Développement local

```bash
npm install
npm run dev
npm run build
```

## Technologies

React, TypeScript, Vite, Tailwind CSS et Supabase.

## Déploiement

Le déploiement de l'application est configuré depuis GitHub.
